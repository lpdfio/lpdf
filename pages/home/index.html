Highlights

Layout system, simplified coordinates, data-binding built-in, no third-party dependencies.

Layout primitives that just work
Stack, Flank, Split, Cluster, Grid, Frame — describe document intent in layout terms. The engine resolves positions, wraps text, and handles page breaks automatically.
Every language you ship
Native adapters for Node.js, .NET, PHP, and Python. Browser and VS Code too. One format, same output, wherever you run — byte-identical across all adapters.
Under 200ms per document
Rust core compiled to WASM. No headless browser, no subprocess, no waiting. A fully paginated invoice with tables and barcodes renders in milliseconds on commodity hardware.
Tables that paginate cleanly
Tables with fr/pt/% column widths, row striping, cell borders, and thead rows that repeat automatically on every new page. Complex layouts with zero boilerplate.
Data binding built in
data-value, data-source, data-if — three attributes cover the full dynamic layer. Pass a JSON payload at render time; no separate template engine required.
Live preview in VS Code
The Lpdf VS Code extension renders your XML as you type. XSD-backed autocomplete, schema validation, data binding UI, code generation to any supported language, and one-click PDF export.
