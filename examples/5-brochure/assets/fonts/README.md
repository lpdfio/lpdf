# Fonts in this example

Both are under the SIL Open Font License 1.1, which allows embedding in a document and
redistributing the file with it.

- `Radley-Regular.ttf`: the display serif. The licence text is `OFL-Radley.txt`.
- `Montserrat-Regular.ttf`: the text sans, version 9.000, the same file the demo uses. The licence text is
  `OFL-Montserrat.txt`, from the upstream project with the copyright line of this font file.

Each has one weight, so the brochure sets hierarchy with size and colour.
